# Reimagine outcomes

- [x] **Upload, validate, and manage source photos:** Provide drag-and-drop or file-picker upload for black-and-white images; show an uploaded-image preview with clear file validation and replace/remove controls. Validate JPEG/PNG/WebP MIME and image signatures and enforce the 15 MB limit before requesting signed storage; keep project-service credentials out of browser code and store originals under collision-resistant object keys.
- [x] **Vibrant AI colorization with skin-tone care:** Colorize a selected black-and-white photo using the available built-in image-edit model, yielding richer, naturally plausible scene colors rather than a dull sepia-only tint. Instruct the model to preserve each person's individual complexion and undertone, facial identity, and detail without artificial lightening, darkening, or orange saturation. Show progress and actionable errors, never quietly substitute a fake filter for failed inference, and tell users that colors are estimates and skin tones should be reviewed.
- [x] **Before-and-after inspection:** Provide an interactive before-and-after comparison slider showing the actual model result alongside the untouched original, plus a side-by-side view. Make comparison controls keyboard-accessible and responsive.
- [x] **Download and responsive accessible workflow:** Provide a download control for saving the finished AI colorized result as PNG, make the interface responsive and accessible, and include clear empty, loading, success, and error states.
- [x] **Secure photo file handling:** Store uploaded originals and generated colorized results securely so the processing workflow can reliably access image files. Keep runtime credentials and presigned URLs server-side; use validated uploads and scoped presigned transfers with separate randomized project-storage paths for original and model-generated result. Tell users in the upload panel that colorization sends photos to AI, project-storage links are not private per user, and sensitive photos should be avoided. This prototype does not provide private per-user authorization, ownership, or deletion; see the README privacy limitation.

- [x] **Rebrand and simplify navigation:** “Remove how it works section,navigator option and change the name to reimagine.” Remove the How it works section and its navigation link; use Reimagine as the visible brand.
- [x] **Show the full photo:** “the preview is not showing full image from top to bottom.” Ensure the complete image is visible from top to bottom in slider and side-by-side previews without cropping.
- [x] **Polish the interface:** “make sure the ui attractive a bit more.” Refine the Reimagine workbench presentation while keeping it clean, understandable, and creative.
